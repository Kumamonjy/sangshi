=============================================
一、游戏基本信息
游戏名称：养成战棋
目标平台：uni-app（适配安卓手机 + MuMu 模拟器）
游戏类型：养成类回合制战棋（SRPG）
核心玩法一句话：玩家在主界面可查看可养成主角的人物信息、进入战斗，在 12 行 11 列网格地图上操控所有己方角色（可养成主角），通过回合制移动 / 攻击、释放技能、原地防御，消灭所有敌方单位；战斗胜利后所有己方主角获得经验、升级并提升属性，战斗过程中支持 2/3 倍速加速，所有角色分属六大职业，各有专属技能及冷却机制，逐步养成强力队伍。
参考方向：简化版《火焰纹章》+ 多主角养成 + 职业技能系统，优先实现核心战斗流程、养成功能、职业技能及加速功能，不做复杂系统（如装备、阵营等），后期可迭代扩展。
=============================================
二、核心玩法规则（修正冲突 + 新增原地防御）
1. 地图与地形
地图规格：固定 12 行 11 列网格（纵向 12 行，横向 11 列），占满手机竖屏，无多余空白区域，格子大小均匀，适配手机操作。
地形类型（仅 2 种，简化规则）：
① 草地：可正常通行，无任何属性影响，所有单位均可移动至此。
② 障碍（石头）：不可通行，单位无法移动至该格子，也无法穿过，不影响技能释放范围；任何角色均可对障碍物发起普通攻击，攻击后障碍物被清除，该次攻击消耗角色的攻击次数。
2. 回合制流程（替换待机为原地防御）
开局：从主界面点击「开始战斗」后，加载并显示 12×11 网格地图，己方可养成主角（玩家选择）和敌方初始角色按固定位置生成，己方角色固定出现在地图下端，敌方角色固定出现在地图上端；可通过主界面「设置」按钮自定义初始化敌我角色人数（双方均为3-10人）。
战斗加速功能：
① 战斗界面顶部状态栏添加「加速」按钮，点击可切换速度模式：正常速度、2 倍速、3 倍速，再次点击可切换回正常速度。
② 加速效果：仅加快战斗动画（移动、攻击、技能释放）速度，不改变回合流程、技能冷却、伤害计算等核心逻辑；玩家 / 敌方回合同步遵循当前速度模式。
玩家回合：
① 己方所有可养成主角均可操作，每回合可依次操作每个角色，无操作顺序限制；我方 AI 角色由系统自动操作，玩家无法选中或操纵。
② 点击己方任意可养成主角，地图自动高亮该角色可移动的范围（蓝色格子），同时显示该角色的技能按钮（技能未冷却时可点击，冷却时灰色不可点击）。
③ 操作选项：每个角色每回合可执行「移动 + 攻击」「移动 + 释放技能」「攻击 + 移动」「释放技能 + 移动」或原地防御；仅能执行 1 次攻击 / 技能（二者不可同时执行），操作后不可重复操作。
④ 移动：点击目标可通行格子，角色移动至该位置；释放技能后，若技能无位移效果，角色位置不变。
⑤ 攻击 / 技能：移动后，自动高亮该角色可攻击范围（红色格子）或技能释放范围（对应职业的技能范围），点击目标即可触发攻击或技能。
⑥ 原地防御规则（替换原待机）：选择原地防御后，角色本回合不移动、不攻击、不释放技能；本回合自身防御力提升 10%，计算方式为：最终防御 = 基础防御 ×1.1，结果向上取整数；防御加成仅当前回合生效，回合结束后恢复原有防御数值。
⑦ 所有己方角色操作完成后，点击「结束回合」按钮，切换至敌方回合。
敌方回合：
① AI 自动控制所有敌方角色，依次完成移动、攻击、释放技能或原地防御（逻辑简化：优先攻击距离最近的己方角色，血量偏低时优先选择原地防御，技能冷却结束后优先释放技能）。
② 敌方回合同样支持加速功能，跟随玩家设置的速度模式运行。
AI 角色配置：
- 我方总人数 = 玩家选择的可养成主角 + 自动补充的我方AI角色
- 玩家可在设置中自定义我方总人数（3-10人）和敌方总人数（3-10人）
- 战斗开始时，若玩家选择的角色数量 < 设置的我方总人数，系统自动补充AI角色至满员
- 点击我方AI角色可查看其属性信息
胜负条件：
① 胜利：消灭所有敌方角色（包括中途加入的敌方 AI），弹出「胜利」提示，显示所有己方可养成主角获得的经验值，可返回主界面重新开始战斗或查看人物信息。
② 失败：所有己方角色（包括初始主角和中途加入的己方 AI）被消灭，弹出「失败」提示，所有己方可养成主角不获得任何经验，可返回主界面重新开始。
3. 职业系统（统一描述，无重复）
职业分类：所有角色（己方 3 个可养成主角、敌方初始角色、中途加入的 AI 角色）均属于以下 6 种职业之一，职业决定角色的初始属性、移动力、攻击射程及专属技能：
战士：近战职业，攻防均衡，擅长防御续航。职业图标：🛡️
骑士：近战职业，移动力强，擅长群体伤害。职业图标：⚔️
弓箭手：远程职业，攻击射程远，擅长单体远程打击。
法师：远程职业，擅长范围攻击，群体伤害高。
巫师：辅助职业，擅长队友回血，提升队伍续航。
刺客：近战职业，移动力高，爆发伤害强，擅长背后偷袭。
4. 单位系统（修正属性提升重复、规则冲突）
4.1 初始单位配置
己方：3 个可养成主角，分属 3 种不同职业（例如：战士、弓箭手、法师，可灵活分配），初始均为等级 1，各有初始属性和专属技能；战斗开始时可额外加入 0~7 名我方 AI 角色（根据设置），AI 角色等级与我方主角等级平均值一致。
敌方：默认初始3个角色，分属随机职业，初始等级与我方主角等级平均值一致，各有初始属性和专属技能；玩家可在设置中调整初始敌人数量（3~10个），或通过战斗中支援机制增加敌人（最多3次，每次1人）。
中途加入 AI 角色：初始等级与当前战斗中双方平均等级一致，职业随机，属性随机（贴合对应职业特性），自带对应职业技能。
4.2 各职业初始属性（统一标准）
战士：等级 1，生命值 18，攻击力 6，防御力 2，移动力 3，攻击射程 1（近战），初始经验 0/50
骑士：等级 1，生命值 20，攻击力 6，防御力 1，移动力 4，攻击射程 1（近战），初始经验 0/50
弓箭手：等级 1，生命值 16，攻击力 7，防御力 1，移动力 3，攻击射程 3（远程），初始经验 0/50
法师：等级 1，生命值 14，攻击力 7，防御力 1，移动力 3，攻击射程 3（远程），初始经验 0/50
巫师：等级 1，生命值 16，攻击力 5，防御力 2，移动力 3，攻击射程 3（远程），初始经验 0/50
刺客：等级 1，生命值 16，攻击力 7，防御力 0，移动力 3，攻击射程 1（近战），初始经验 0/50
4.3 伤害公式
伤害 = 攻击者攻击力 - 目标防御力（最低造成 1 点伤害，不会出现 0 伤害；范围攻击时，对范围内每个目标均按此公式计算伤害；原地防御的 10% 防御加成参与伤害计算）。
4.4 视觉提示
① 选中角色时，高亮可移动范围（蓝色）、可攻击范围（红色）、技能释放范围（对应职业的技能范围，如法师 3×3 范围为紫色半透明覆盖）。
② 人物造型与视觉区分：不同职业的人物造型完全不同，通过职业图标（emoji）区分职业类型；3 个可养成主角有红色五角星（★）标识，与其他AI角色区分明显；战斗过程中，玩家可通过职业图标和五角星标识直接区分敌我双方、是否为主角。
③ 技能冷却时，技能按钮灰色显示，并标注剩余冷却回合数；技能可释放时，按钮正常显示，点击后触发技能动画。
④ 角色选择原地防御后，人物添加简易防御姿态标识，直观提示当前处于防御加成状态。
⑤ 游戏字幕系统：每个角色（包括主角和AI）使用技能、普通攻击、防御或清除障碍物时，都会在战斗地图和底部按钮之间显示字幕说明，移动操作不显示字幕。
   - 字幕格式示例：
     - 敌方【巫师】对我方【弓箭手】使用【普通攻击】
     - 我方【战士】使用技能【防御姿态】
     - 我方【弓箭手】对敌方【法师】使用技能【远程射击】
     - 敌方【战士】对己方【刺客】使用【普通攻击】
⑥ 地图道具：每局战斗开始时，地图中间几行随机生成2个回血草（🌿），任何角色移动停留到回血草上可立即恢复30%最大生命值（向上取整），使用后回血草消失。
⑦ 血条显示：所有角色头顶显示血条，血条高度清晰可见，实时显示角色当前生命值与最大生命值的比例。
⑧ 障碍物标识：地图障碍物显示为🗿图标。
5. 技能系统（统一规则，删除重复）
技能通用规则：
① 所有角色（主角、敌方、AI）均拥有对应职业的专属技能，技能仅可在自身回合释放，释放后进入冷却状态，冷却结束前不可再次释放。
② 冷却回合计算：技能释放后，从下一个回合开始计算冷却，冷却回合数结束后，技能自动恢复可释放状态（例：冷却 2 回合，本回合释放，下下个回合可再次释放）。
③ 技能释放优先级：高于普通攻击，可选择「释放技能」或「普通攻击」，二者不可同时执行；释放技能后，仍可进行移动操作（技能无位移时）。
各职业专属技能及冷却机制：
弓箭手 - 远程射击：对单个敌方目标造成 1.3 倍普通攻击伤害，攻击射程提升至 4 格，冷却 3 回合
法师 - 范围爆破：以自身为中心，对 3×3 范围内的所有敌方目标造成普通攻击伤害（不伤害己方），冷却 3 回合
骑士 - 冲锋：向指定方向直线移动（最大距离 = 自身移动力），路径上敌方受普攻伤害；遇障碍中断，停在终点，冷却 3 回合
战士 - 防御姿态：回复15%血量，接下来2回合防御力+3，冷却3回合
巫师 - 治愈术：对单个己方目标恢复生命值（恢复量 = 巫师攻击力 ×2），技能射程 3 格，冷却 3 回合
刺客 - 暗影打击：瞬间移动到5格范围内的任何位置发动攻击，攻击力为普通攻击×1.3（向上取整），冷却 3 回合
6. 养成系统（修正属性提升重复描述，统一规则）
经验与金币获取：
① 战斗胜利：所有己方存活的主角和雇佣兵获得经验，经验值 = 固定20 + 击杀敌人数 × 10；金币 = 消灭敌方角色数量 ×10。
② 战斗失败：无经验、无金币。
③ 中途加入的己方 AI 不获得经验，不可养成。
金币用途：
① 雇佣新可养成主角：100 金币 / 名；解雇可养成主角：获得 50 金币 / 名。
② 金币仅通过战斗胜利、解雇角色获得，无其他途径。
升级规则：
① 可养成主角（初始 3 个 + 雇佣角色）独立升级，初始 3 个主角为 1 级，雇佣角色为 0 级。
② 升级阈值（统一标准）：
0→1：50 点
1→2：80 点
2→3：110 点
3→4：140 点
4→5：170 点
5→6：200 点
6→7：230 点
7→8：260 点
8→9：290 点
9→10：320 点
10 级及以上：每级阈值增加 30 点
属性提升（核心规则：每 2 级额外 + 1 点防御，区分奇偶等级）：
战士：奇数级别生命 + 4、攻击 + 1、防御 + 1；偶数级别生命 + 4、攻击 + 1、防御 + 2
骑士：奇数级别生命 + 3、攻击 + 1、防御 + 1；偶数级别生命 + 3、攻击 + 1、防御 + 2
弓箭手：奇数级别生命 + 2、攻击 + 2、防御 + 0；偶数级别生命 + 2、攻击 + 2、防御 + 1
法师：奇数级别生命 + 2、攻击 + 2、防御 + 0；偶数级别生命 + 2、攻击 + 2、防御 + 1
巫师：奇数级别生命 + 3、攻击 + 1、防御 + 0；偶数级别生命 + 3、攻击 + 1、防御 + 1
刺客：奇数级别生命 + 3、攻击 + 2、防御 + 0；偶数级别生命 + 3、攻击 + 2、防御 + 1
注：所有职业移动力、攻击射程升级后均不提升；等级上限初始为 10 级。
经验与等级显示：主界面「人物信息」可查看所有可养成主角的等级、经验、属性、职业、技能信息。

三、界面设计（修正重复 + 适配原地防御）
1. 主界面
顶部：
① 居左：「设置」按钮（齿轮图标），点击弹出设置弹窗。
② 居中：游戏标题「养成战棋」。
③ 居右：金币数量（实时更新）。
设置弹窗功能：
① 调整初始角色数量：敌方 AI（3~10，默认 3）、我方 AI（0~7，默认 0）。
② 实时保存设置，关闭弹窗后生效。
③ 显示我方总人数 = 3 个主角 + 我方 AI 数量。
中间核心区域：垂直排列 3 个按钮（尺寸适中、间距均匀）：
① 「人物信息」：进入人物信息界面，查看所有可养成角色（主角和雇佣兵）详情。
② 「开始战斗」：进入战斗界面。
③ 「雇佣 / 解雇」：进入雇佣解雇界面。
底部：居中提示文字「战斗胜利可获得经验和金币，提升主角等级与属性；战斗中可点击加速按钮切换速度；可通过雇佣按钮扩展主角团；回合可选择原地防御提升本回合 10% 防御」（小字体）。
整体风格：浅灰色背景，无多余元素，按钮区分明显。
1.1 雇佣 / 解雇界面
顶部：
① 居中：「雇佣 / 解雇」标题。
② 居左：「返回主界面」按钮。
③ 居右：当前金币数量。
雇佣功能：
① 点击「雇佣新角色」：消耗 100 金币，随机生成 1 名 0 级可养成主角（职业随机，初始属性为对应职业 80%，向下取整）。
② 自定义命名：弹出输入框（支持中英，默认「新角色 - 职业简称」）。
③ 金币不足：弹窗提示「金币不足，无法雇佣」。
解雇功能：
① 显示所有可养成角色（主角和雇佣兵），每个角色旁加「解雇」按钮。
② 点击解雇：确认后获得 50 金币，角色数据清除（不可恢复）。
③ 限制：主角不可被解雇，雇佣兵可被解雇。
整体风格：与主界面统一，操作清晰，提示明确。
2. 人物信息界面
顶部：
① 居中：「人物信息」标题。
② 居左：「返回主界面」按钮。
③ 居右：「切换角色」按钮（循环切换所有可养成角色，包括主角和雇佣兵）。
中间核心区域（垂直排列，字体清晰）：
① 角色标识：「名称」+ 职业图标 + 可修改名称按钮（点击进入编辑模式）+ 主角标识（仅主角显示）。
② 等级信息：「等级：X 经验：X/X」。
③ 属性信息：「生命值：X（+X / 级）、攻击力：X（+X / 级）、防御力：X（+X / 级）、移动力：X、攻击射程：X」。
④ 技能信息：「技能：XXX - 效果：XXX 冷却：X 回合」。
⑤ 职业切换：显示所有职业选项，点击可切换职业（主角和雇佣兵都支持）。
整体风格：简洁无冗余，信息易读，切换流畅。
3. 战斗界面
顶部状态栏（占屏幕 1/10）：
① 左侧：当前回合（「玩家回合」/「敌方回合」）。
② 中间：「加速」按钮（显示当前速度，点击切换：正常→2 倍→3 倍→正常）。
③ 右侧：双方剩余单位（「己方：X/X 敌方：X/X」，实时更新）。
中间核心区域（占屏幕 8/10）：15×10 网格地图，清晰区分地形、角色；主角加黄色边框，技能范围对应颜色半透明覆盖（法师 3×3 = 紫色）。
底部操作栏（占屏幕 1/10）：
① 选中角色：显示「技能按钮」「原地防御」「结束回合」按钮；技能按钮标注名称 / 冷却数，冷却时灰色锁定。

四、技术实现要求（修正重复 + 适配原地防御）
1. 开发框架
使用 uni-app + Vue3 开发，兼容 HBuilderX，可运行在 MuMu 模拟器 / 安卓手机。
2. 开发优先级
优先实现：14×10 地图生成 → 核心战斗流程（移动 / 攻击 / 回合切换 / 原地防御） → 主界面 / 人物信息 / 雇佣解雇界面 → 3 个主角养成 → 职业 / 技能系统（含冷却） → 战斗加速 → 中途 AI 加入；后实现界面美化，不添加需求外功能（音效、复杂动画、装备等）。
3. 核心功能必须实现
① 基础功能：地图生成、单位生成 / 移动 / 攻击 / 原地防御、回合切换、敌方 AI、胜负判断、基础提示。
② 界面功能：主界面按钮跳转、人物信息切换、雇佣 / 解雇（命名 / 金币 / 数量限制）、金币实时更新。
③ 养成功能：可养成主角独立经验 / 升级 / 属性提升，人物信息实时更新。
④ 职业技能：职业分配、技能释放 / 冷却 / 效果（法师范围不伤及己方、骑士冲锋遇障碍中断）。
⑤ 原地防御功能：每回合可选择原地防御，不移动不行动，本回合防御 + 10%、向上取整，仅当前回合生效，AI 角色也具备原地防御逻辑。
⑥ 加速功能：速度切换仅影响动画，不改变核心逻辑、防御加成、技能冷却。
⑦ AI 加入：随机触发、随机阵营 / 位置 / 职业，加入后正常参与回合，无角色重叠 / 操作异常。
⑧ 视觉区分：按规则区分敌我 / AI / 主角 / 技能范围 / 防御状态，无混淆。
4. 数据存储
所有数据（主角等级 / 经验 / 属性、金币、技能冷却、回合进度、防御加成状态等）均为本地临时存储，重启游戏重置为初始状态（3 个 1 级主角、金币 100、无雇佣角色）。
5. 代码要求
分模块开发（地图、单位、回合、AI、界面、养成、技能、加速、防御模块），结构清晰，添加必要注释；技能 / 加速 / AI 加入 / 原地防御逻辑独立编写，避免冲突。
6. 适配要求
竖屏布局，适配主流手机 / MuMu 模拟器；地图无错位 / 遮挡，按钮 / 文字 / 格子大小适中；界面 / 主角 / 速度切换流畅无卡顿；技能动画、防御标识简洁不影响操作。
7. 异常处理
① 避免点击无响应、角色卡 BUG、回合切换异常、经验 / 金币计算错误、属性升级不更新。
② 确保技能逻辑正确（冷却计算、效果触发）、原地防御 10% 加成计算准确、向上取整规则无误。
③ AI 加入后统计准确、加速不影响防御加成与核心逻辑。
④ 雇佣 / 解雇功能正常（金币消耗 / 获得准确、命名正常、不可解雇至 0 人）。
⑤ 视觉区分、防御状态标识清晰，可准确识别角色状态。
