# 养成战棋游戏

## 项目概览

养成战棋是一款基于 **uni-app + Vue3** 开发的回合制策略游戏，玩家可以培养主角团队，在12×11的网格地图上进行战斗，通过策略性的移动、攻击和技能释放来击败敌人。

## 核心功能

### 1. 回合制战斗系统
- **地图规格**: 12×11网格地图
- **操作模式**: 移动（蓝色范围）、攻击（红色范围）、技能（紫色范围）、防御
- **回合机制**: 玩家回合→敌方AI回合循环
- **战斗加速**: 支持1x/2x/3x战斗加速
- **字幕系统**: 实时显示角色动作（攻击/技能/防御/清除障碍物）
- **天气系统**: 每回合50%概率下雪，生成2个3×3雪地区域，处于雪地的角色无法移动（可攻击/技能/防御）

### 2. 职业系统

| 职业 | 图标 | 生命 | 攻击 | 防御 | 移动力 | 攻击射程 | 技能 | 冷却 |
|------|------|------|------|------|--------|----------|------|------|
| 战士 | ⚔️ | 高 | 中 | 中 | 3 | 1 | 防御姿态 | 3回合 |
| 骑士 | 🛡️ | 高 | 中 | 中 | 4 | 1 | 冲锋 | 3回合 |
| 弓箭手 | 🏹 | 中 | 高 | 低 | 3 | 3 | 远程射击 | 2回合 |
| 法师 | 🔮 | 低 | 高 | 低 | 3 | 3 | 范围爆破 | 3回合 |
| 巫师 | 💀 | 中 | 低 | 中 | 3 | 3 | 治愈术 | 3回合 |
| 刺客 | 🗡️ | 中 | 高 | 低 | 3 | 1 | 暗影打击 | 3回合 |

**技能详细说明**:
- **防御姿态（战士）**: 回复15%血量，接下来2回合防御力+30
- **冲锋（骑士）**: 直线移动，路径上敌人受伤害
- **远程射击（弓箭手）**: 1.5倍伤害，射程4格
- **范围爆破（法师）**: 3×3范围伤害
- **治愈术（巫师）**: 恢复量=攻击力×2，射程3格
- **暗影打击（刺客）**: 瞬移5格内任意位置攻击，1.3倍伤害

### 3. 养成系统

**主角系统**:
- 初始3个主角：熊熊（战士）、兔兔（弓箭手）、大黑熊（法师）
- 主角不可被解雇，只有雇佣兵可以被解雇
- 主角支持自定义头像：放置 `hero_1.png`、`hero_2.png`、`hero_3.png` 到 `src/static/` 目录即可替换默认图标

**经验与金币**:
- 经验值 = 20 + 击杀敌人数 × 10
- 金币 = 击杀敌人数 × 10

**角色管理**:
- 雇佣角色：100金币
- 解雇角色：返还50金币（仅雇佣兵可解雇）
- 重命名：支持1-4个中文字符
- 切换职业：经验值和天赋点保持不变，已使用的天赋点全部返还

**天赋点系统**:
| 等级 | 天赋点获得 |
|------|-----------|
| 1级 | 1点（初始） |
| 每次升级 | 1点 |

**天赋点分配**:
- ❤️ 生命+3（消耗1点）
- 🗡️ 攻击+1（消耗1点）
- 🛡️ 防御+1（消耗1点）

### 4. 地图与障碍物

- **障碍物**: 随机生成12-16个，显示为🗿图标，所有角色可攻击清除
- **回血草**: 每局开始时地图中间随机生成2个（🌿），停留可恢复30%最大生命（向上取整），使用后消失
- **地图连通性**: 使用BFS算法确保无死路
- **天气系统**:
  - 每回合开始时50%概率下雪
  - 下雪时随机生成2个3×3雪地区域（❄️）
  - 处于雪地的角色无法移动，但可攻击、使用技能、防御
  - 雪地区域背景为浅蓝色渐变，带有雪花动画

### 5. AI系统

- **敌方AI**: 自动移动攻击，优先攻击最近目标
- **AI技能**: 技能冷却结束后优先释放；战士只有在不满血时使用防御姿态
- **呼叫支援**: 玩家手动点击顶部按钮，敌我双方同时各加入1名AI（最多3次）
- **等级计算**: 敌方角色等级 = 我方上场角色等级平均值（向下取整）
- **入场位置**: 敌方新角色只能出现在最上方两行，我方新角色只能出现在最下方两行

### 6. 属性计算系统

**初始属性（1级）**:

| 职业 | 生命值 | 攻击力 | 防御力 |
|------|--------|--------|--------|
| 战士 | 190 | 60 | 20 |
| 骑士 | 200 | 60 | 10 |
| 弓箭手 | 160 | 70 | 10 |
| 法师 | 150 | 70 | 10 |
| 巫师 | 160 | 50 | 20 |
| 刺客 | 160 | 70 | 0 |

**升级属性提升（每级）**:

| 职业 | 生命+ | 攻击+ | 防御+ |
|------|-------|-------|-------|
| 战士 | 40 | 10 | 15 |
| 骑士 | 40 | 15 | 10 |
| 弓箭手 | 30 | 15 | 5 |
| 法师 | 30 | 15 | 5 |
| 巫师 | 40 | 5 | 15 |
| 刺客 | 30 | 15 | 5 |

**天赋点分配**:
- ❤️ 生命+30（消耗1点）
- 🗡️ 攻击+10（消耗1点）
- 🛡️ 防御+10（消耗1点）

**雇佣兵说明**:
- 雇佣兵与主角享有相同的属性和成长
- 雇佣兵和主角都可以切换职业、重命名、分配天赋点

**伤害计算**: 伤害 = 攻击力 - 防御力（最低1点），结果向上取整

**属性显示**: 所有属性值四舍五入保留整数

## 游戏玩法

### 开始界面
1. **全新游戏**: 重置所有数据，进入主界面
2. **载入存档**: 加载之前保存的游戏进度

### 主界面操作
1. **人物信息**: 查看所有可养成角色的属性、技能，分配天赋点
2. **开始战斗**: 先选择3名参战角色，进入战斗
3. **雇佣/解雇**: 扩展或精简主角团
4. **保存游戏**: 点击右上角💾按钮保存当前进度
5. **设置**: 调整游戏参数

### 游戏存档
- **存储内容**: 存档版本号、主角/雇佣兵属性、金币、游戏设置
- **存档位置**: 本地存储（uni.getStorageSync）
- **存档槽位**: 最多3个存档（gameSave_0、gameSave_1、gameSave_2）
- **备份存档**: 自动保存（gameSave_backup）
- **存档命名**: 保存时可自定义存档名称
- **存档显示**: 存档名称、保存时间（yyyyMMdd HH:mm:ss）、金币数量
- **自动保存**: 无（需手动点击保存按钮）
- **数据迁移**: 自动迁移旧版本存档数据
- **备份恢复**: 加载失败时自动尝试从备份恢复
- **血条显示**: 敌方红色，我方绿色，无低血量警告

### 战斗操作
1. 点击己方角色选中（显示蓝色可移动范围）
2. 点击蓝色格子移动角色
3. 选择攻击模式（红色范围）或技能模式（紫色范围）
4. 点击目标执行攻击或释放技能
5. 选择原地防御提升10%防御力（仅本回合生效）
6. 所有角色操作完成后点击"结束回合"
7. 点击我方AI角色可查看其属性（无操作按钮）
8. 点击敌方角色可查看其属性

### 胜负条件
- **胜利**: 消灭所有敌方单位
- **失败**: 所有己方单位被消灭

## 核心数据结构

### Unit（角色单位）
```typescript
interface Unit {
  id: string                    // 唯一标识
  name: string                  // 角色名称
  classType: 'warrior' | 'knight' | 'archer' | 'mage' | 'witch' | 'assassin'
  isHero: boolean               // 是否为主角
  isAI: boolean                 // 是否为AI控制
  isEnemy: boolean              // 是否为敌方
  level: number                 // 等级
  exp: number                   // 当前经验
  statPoints: number            // 剩余天赋点
  usedStatPoints: number        // 已使用天赋点
  maxHp: number                 // 最大生命值
  hp: number                    // 当前生命值
  attack: number                // 攻击力
  defense: number               // 防御力
  moveRange: number             // 移动范围
  attackRange: number           // 攻击射程
  skill: {
    name: string                // 技能名称
    description: string         // 技能描述
    cooldown: number            // 冷却回合数
    currentCooldown: number     // 当前冷却剩余
  }
  position: { row: number; col: number }  // 地图位置
  isDefending: boolean          // 是否处于防御状态
  hasActed: boolean             // 本回合是否已行动
  hasMoved: boolean             // 本回合是否已移动
  hasAttacked: boolean          // 本回合是否已攻击
  defenseBuffDuration: number   // 防御buff剩余回合
}
```

### GameStore（状态管理）

**核心方法**:

| 方法名 | 功能说明 | 参数 |
|--------|----------|------|
| `hireHero` | 雇佣新角色 | `classType`: 职业类型 |
| `fireHero` | 解雇角色 | `heroIndex`: 角色索引 |
| `renameHero` | 重命名角色 | `heroId`: 角色ID, `newName`: 新名称 |
| `changeHeroClass` | 切换职业 | `heroIndex`: 角色索引, `newClass`: 新职业 |
| `addHeroStat` | 分配天赋点 | `heroIndex`: 角色索引, `statType`: 属性类型, `value`: 增加值 |
| `awardExpToHeroes` | 发放经验 | `exp`: 经验值 |
| `toggleBattleUnitSelection` | 切换参战选择 | `unitId`: 角色ID |
| `saveGame` | 保存游戏 | - |
| `loadGame` | 加载游戏 | - |
| `startBattle` | 开始战斗 | - |
| `selectUnit` | 选择单位 | `unit`: 单位对象 |
| `moveUnit` | 移动单位 | `row`: 目标行, `col`: 目标列 |
| `setAttackMode` | 设置攻击模式 | - |
| `setSkillMode` | 设置技能模式 | - |
| `executeAttack` | 执行攻击 | `target`: 目标单位 |
| `executeSkill` | 释放技能 | `target`: 目标单位 |

| `endTurn` | 结束回合 | - |

## 数据存储说明

**存档系统**:
- 使用 `uni.setStorageSync` / `uni.getStorageSync` 实现本地存储
- 存档键名: `gameSave_0/1/2`（3个槽位）
- 备份键名: `gameSave_backup`
- 存储内容: 存档版本号、金币、主角/雇佣兵完整属性、游戏设置
- 新游戏会清除存档
- 数据迁移: 自动将旧版本存档迁移到新版本
- 备份机制: 每次保存时自动备份，加载失败时自动恢复

**存档数据结构**:
```typescript
{
  version: number            // 存档版本号
  saveName: string           // 存档名称
  savedAt: string            // 保存时间
  gold: number               // 金币
  heroes: Unit[]             // 英雄列表
  settings: GameSettings     // 游戏设置
}
```

**初始状态**:
- 3个1级主角：战士-熊熊、弓箭手-兔兔、法师-大黑熊
- 金币：100
- 无雇佣角色

## 开发注意事项

1. **技能冷却机制**: 技能释放后从下一回合开始计算冷却
2. **防御加成**: 原地防御提升10%防御，仅当前回合生效
3. **战士技能**: 防御姿态可回复15%血量并使接下来2回合防御力+5
4. **AI等级计算**: 敌方角色等级等于我方上场角色等级平均值（向下取整）
5. **地图连通性**: 随机障碍物生成时使用BFS确保无死路
6. **伤害计算**: 伤害 = 攻击力 - 防御力（最低1），结果向上取整
7. **回血草**: 停留可恢复30%最大生命（向上取整），使用后消失；骑士技能移动到草药位置时自动使用
8. **呼叫支援**: 最多3次，敌我双方同时各加入1名AI
9. **主角保护**: 主角不可被解雇，只有雇佣兵可以被解雇
10. **属性显示**: 所有属性值四舍五入保留整数
11. **主角头像**: 三个主角（熊熊、兔兔、大黑熊）支持自定义头像，放置 `hero_1.png`、`hero_2.png`、`hero_3.png` 到 `src/static/` 目录即可替换
12. **雇佣兵属性**: 雇佣兵与主角享有相同的属性和成长，无80%限制
13. **血条显示**: 敌方红色，我方绿色，无低血量警告
14. **经验分配**: 只有参战角色获得经验
15. **角色属性**: 使用等级增长计算，而非乘法
16. **存档系统**: 支持版本号、数据迁移、自动备份和备份恢复

## 代码规范

- 使用TypeScript类型定义，确保类型安全

- 函数职责单一，避免过长方法（建议不超过50行）

- 变量命名采用驼峰式（camelCase）
- 文件名采用小写加连字符（kebab-case）

## 贡献指南

欢迎提交Issue和Pull Request！

### 开发流程
1. Fork本仓库
2. 创建功能分支：`git checkout -b feature/xxx`
3. 提交代码：`git commit -m "feat: xxx"`
4. 推送分支：`git push origin feature/xxx`
5. 创建Pull Request

### 代码审查
- 确保所有功能测试通过
- 代码符合TypeScript规范
- 关键逻辑有适当注释
- 不引入未使用的依赖
