## 核心模块详解

### stores/gameStore.ts

**职责**: 游戏全局状态管理，包含所有游戏数据和操作方法

**核心常量**:
- `SAVE_VERSION`: 存档版本号（当前为2），用于数据迁移

**新增核心函数**:
- `migrateSaveData(data)`: 数据迁移函数，将旧版存档迁移到新版
- `saveGame(saveName?)`: 保存游戏（自动备份）
- `saveGameOverwrite(saveName, slotIndex)`: 覆盖保存（自动备份）
- `loadGame(slotIndex)`: 加载游戏（含备份恢复）

**状态定义**:

| 状态 | 类型 | 说明 |
|------|------|------|
| gold | number | 当前金币数量 |
| heroes | Unit[] | 所有可养成角色列表 |
| selectedBattleUnits | string[] | 选中参战的角色ID列表 |
| settings | GameSettings | 游戏配置（敌人数量、等级范围等） |
| battle | BattleState | 当前战斗状态 |
| aiJoinMessage | string | AI加入提示信息 |
| showAiJoinMessage | boolean | 是否显示AI加入提示 |
| battleLog | BattleLogEntry[] | 战斗日志记录（按回合分组） |

**核心方法分类**:

1. **游戏控制**: startBattle(), endPlayerTurn(), clearBattle(), resetGame()
2. **战斗操作**: selectUnit(), moveUnit(), attackTarget(), useSkillTarget(), defend(), confirmArchitectSkill()
3. **角色管理**: hireHero(), fireHero(), renameHero(), toggleBattleUnitSelection()
4. **设置管理**: updateSettings(), setSpeed()
5. **天气系统**: updateWeather(), generateSnowAreas(), generateThunderAreas(), isInSnowArea(), isInThunderArea(), applyThunderDamage()
6. **战斗日志**: addBattleLog(), clearBattleLog()

---

### utils/gameData.ts

**职责**: 游戏数据定义、工具函数、核心算法

**数据结构**:

1. **Unit**: 单位数据结构（属性、技能、位置等）
2. **GameSettings**: 游戏配置结构
3. **BattleState**: 战斗状态结构
4. **CLASS_CONFIG**: 各职业初始属性配置

**核心函数**:

| 函数 | 职责 |
|------|------|
| createUnit() | 创建单位实例 |
| generateRandomObstacles() | 随机生成障碍物（BFS确保连通） |
| getAvailablePositions() | BFS计算可移动位置 |
| getAttackablePositions() | 计算可攻击目标 |
| getSkillRangePositions() | 计算技能释放范围 |
| calculateDamage() | 计算伤害 |
| useSkill() | 执行技能效果 |
| getLevelUpStats() | 获取升级属性提升 |

## 数据流与状态管理

### 状态流向图

```
用户操作 → Action → State变化 → View更新
     ↓
例如：雇佣角色
     ↓
hireHero() → 检查金币 → 创建新角色 → heroes.push() → gold -= 100 → 界面更新
```

### 战斗状态流转

```
startBattle()
    ↓
初始化战场（单位、障碍物）
    ↓
battle.currentTurn = 'player'
    ↓
用户操作（移动、攻击、技能）
    ↓
endPlayerTurn()
    ↓
battle.currentTurn = 'enemy'
    ↓
executeEnemyTurn()（AI自动操作）
    ↓
endEnemyTurn()
    ↓
检查胜负 → 胜利/失败 或 下一轮
```

### 响应式依赖

| 组件 | 依赖状态 | 响应行为 |
|------|----------|----------|
| battle.vue | battle.units | 单位列表变化时更新地图 |
| battle.vue | battle.selectedUnit | 选中状态变化时更新高亮 |
| battle.vue | battle.moveMode | 移动模式切换时显示可移动范围 |
| select.vue | selectedBattleUnits | 选择状态变化时更新UI |

## 战斗流程详解

### 天气系统

每回合开始时（敌方回合结束→玩家回合开始）触发天气系统：
```
1. 随机选择天气类型
    ├─ 20% 晴天
    ├─ 10% 小雪 → 生成1个3×3区域
    ├─ 20% 中雪 → 生成2个3×3区域
    ├─ 10% 大雪 → 生成3个3×3区域
    ├─ 10% 小雷雨 → 生成6个1×1区域
    ├─ 20% 中雷雨 → 生成3个2×2区域
    └─ 10% 大雷雨 → 生成5个2×2区域
    ↓
2. 雪地区域避开障碍物和重叠
   雷电区域避开障碍物
    ↓
3. 显示天气提示和战斗日志
    ↓
4. 处于雪地的角色无法移动（可攻击/技能/防御）
   处于雷电区域的角色每回合结束受到50%最大生命值伤害
```

### 雷电伤害应用

每回合结束时（endEnemyTurn后）触发：
```
1. 遍历所有单位
    ↓
2. 检查是否在雷电区域且生命值>0
    ↓
3. 计算伤害 = 50%最大生命值
    ↓
4. 更新单位生命值
    ↓
5. 显示伤害字幕
    ↓
6. 添加战斗日志记录
```

### 玩家回合流程

```
1. 点击己方角色（未行动）
    ↓
2. 自动进入移动模式，显示蓝色可移动范围
    ↓
3. 选择操作：
   a) 移动 → 点击蓝色格子 → 角色移动 → 移动模式关闭
   b) 攻击 → 切换攻击模式 → 显示红色可攻击范围 → 点击目标 → 攻击
   c) 技能 → 切换技能模式 → 显示紫色技能范围 → 点击目标 → 释放技能
   d) 防御 → 进入防御状态 → 本回合防御力+10%
    ↓
4. 操作完成后角色标记为已行动
    ↓
5. 所有角色操作完成后点击"结束回合"
```

### 敌方回合流程

```
1. 获取所有未行动的敌方单位
    ↓
2. 遍历每个敌方单位：
   a) 等待660ms（根据速度调整）
   b) 检查血量（<30%则防御）
   c) 检查技能冷却（可用则释放技能）
      - 刺客：使用useSkill()确保位置正确更新
      - 骑士：使用useSkill()确保位置正确更新
      - 弓箭手：只攻击一个目标
   d) 否则寻找最近玩家单位
   e) 计算最优移动位置（优先非雷电格子，接近目标，检查位置未被占据）
      - 若当前在雷电区域，优先寻找非雷电格子
      - 所有位置按：非雷电优先 > 距离目标近
   f) 若能移动到非雷电格子则移动
      否则在原地执行攻击/技能/防御
   g) 攻击范围内的玩家单位（优先低血量）
    ↓
3. 所有敌方单位行动完成
    ↓
4. 检查AI加入（30%概率）
    ↓
5. 进入下一轮玩家回合
```

### 友方AI回合流程

```
1. 获取所有未行动的友方AI单位
    ↓
2. 遍历每个友方AI单位：
   a) 等待660ms（根据速度调整）
   b) 检查血量（<30%则防御）
   c) 检查技能冷却（可用则释放技能）
      - 刺客：使用useSkill()确保位置正确更新
      - 骑士：使用useSkill()确保位置正确更新
      - 弓箭手：只攻击一个目标
   d) 否则寻找最近敌方单位
   e) 计算最优移动位置（优先非雷电格子，接近目标，检查位置未被占据）
      - 若当前在雷电区域，优先寻找非雷电格子
      - 所有位置按：非雷电优先 > 距离目标近
   f) 若能移动到非雷电格子则移动
      否则在原地执行攻击/技能/防御
   g) 攻击范围内的敌方单位（优先低血量）
    ↓
3. 所有友方AI单位行动完成
    ↓
4. 进入敌方回合
```

### 技能释放流程

```
1. 点击技能按钮（技能未冷却）
    ↓
2. 计算技能范围，显示紫色高亮
    ↓
3. 如果是建筑师：
   a) 选择最多3个无角色的格子（相邻4格内）
   b) 点击"确认"按钮
    ↓
   否则：
   a) 点击目标位置
    ↓
4. 执行useSkill()计算效果：
   - 弓箭手：单体伤害×1.5
   - 法师：3×3范围伤害
   - 骑士：冲锋移动+路径伤害
   - 战士：防御+5（本回合+下回合）
   - 巫师：单体治疗（攻击力×2）
   - 刺客：瞬移+4方向×1.3伤害
   - 建筑师：清除/生成障碍物
    ↓
5. 检查新位置是否有草药（骑士/刺客）
    ↓
6. 如果有草药，自动使用并回复30%最大生命值
    ↓
7. 更新目标状态（血量变化、障碍物变化）
    ↓
8. 设置技能冷却
    ↓
9. 标记角色已行动
```

### 存档系统流程

#### 保存流程
```
1. 调用saveGame()或saveGameOverwrite()
    ↓
2. 构造存档数据（包含version字段）
    ↓
3. 保存到gameSave_backup（自动备份）
    ↓
4. 保存到指定槽位（gameSave_0/1/2）
```

#### 加载流程
```
1. 调用loadGame(slotIndex)
    ↓
2. 尝试从指定槽位读取
    ↓
3. 如果读取失败，尝试从gameSave_backup读取
    ↓
4. 解析JSON数据
    ↓
5. 调用migrateSaveData()进行数据迁移
    ↓
6. 验证数据完整性，缺失字段使用默认值
    ↓
7. 加载数据到游戏状态
    ↓
8. 更新gameSave_backup备份
```

#### 数据迁移流程
```
1. 检查存档的version字段
    ↓
2. 如果version < 1：
   a. 添加heroes默认值
   b. 添加gold默认值
   c. 添加settings默认值
   d. 设置version = 1
    ↓
3. 如果version < 2：
   a. 确保所有hero有完整属性
   b. 设置version = 2
    ↓
4. 返回迁移后的数据
```

## AI行为逻辑

### 敌方AI决策流程

```
AI回合开始
    ↓
检查血量 < 30%？
    ↓ ├─ 是 → 进入防御状态 → 结束
    │
    └─ 否 → 检查技能冷却？
            ↓ ├─ 技能可用 → 释放技能 → 结束
            │
            └─ 技能冷却中 → 寻找最近玩家单位
                              ↓
                          计算可移动位置
                              ↓
                          检查当前位置是否在雷电区域？
                              ↓ ├─ 是 → 优先寻找非雷电格子
                              │
                              └─ 否 → 优先选择非雷电格子
                              ↓
                          对位置进行排序：
                            1. 非雷电位置优先
                            2. 距离目标近优先
                              ↓
                          选择最佳移动位置
                              ↓
                          是否能移动到非雷电格子？
                              ↓ ├─ 是 → 移动到目标位置
                              │
                              └─ 否 → 在原地执行攻击/技能/防御
                              ↓
                          检查攻击范围内是否有玩家
                              ↓ ├─ 有 → 攻击（优先低血量）→ 结束
                              │
                              └─ 无 → 结束
```

### 技能释放优先级

| 优先级 | 条件 | 行为 |
|--------|------|------|
| 1 | 血量 < 30% | 防御 |
| 2 | 技能冷却完成 | 释放技能 |
| 3 | 战士职业（冷却中或无需技能） | 防御 |
| 4 | 其他职业 | 移动并攻击 |

### AI加入逻辑

```
每回合结束时（玩家→敌方 或 敌方→玩家）
    ↓
30%概率触发AI加入
    ↓
随机选择阵营（50%己方，50%敌方）
    ↓
随机选择职业
    ↓
寻找随机空白可通行位置
    ↓
创建AI单位加入战场
    ↓
显示提示信息（3秒后消失）
```

## 代码扩展建议

### 添加新职业

### 添加新功能

1. **装备系统**: 创建装备数据结构，在战斗中应用属性加成
2. **阵营系统**: 添加阵营属性，影响伤害计算或技能效果
3. **地图事件**: 添加宝箱、陷阱等互动元素
4. **成就系统**: 创建成就数据，记录玩家战绩
5. **更多天气类型**: 扩展天气系统，添加雨天（减少攻击力）、雾天（减少视野）等

### 性能优化建议

1. **虚拟滚动**: 当地图变大时使用虚拟滚动优化渲染
2. **对象池**: 复用单位对象减少内存分配
3. **缓存计算**: 缓存移动范围、攻击范围计算结果
