## 修复战斗结束结算窗口不弹出
- 根因：checkBattleEnd（gameStore.ts ~9767）先置 battleMap.battleEnded=true 再 setTimeout 调 endBattle；而 endBattle（~3498）开头 guard `if (battleEnded && !isEscape) return` 导致永远提前返回，battleResult 永不设置，结算弹窗（battle.vue v-if="showResult && battleResult"）永不出现，所有战斗结束均卡死。
- 修复：checkBattleEnd 不再预置 battleEnded（由 endBattle 自己置位），新增局部标志 endBattleScheduled 防重复调度；抽 scheduleEndBattle(victory) 带 try/catch 兜底（结算异常时释放标志并 console.error，避免永久卡死）；战斗初始化（startBattle，battleMap 赋值处 ~3461）重置 endBattleScheduled=false。
- 逃离路径 escapeBattle → endBattle(false, true) 不受影响（isEscape 穿透 guard）。已通过 tsc 过滤检查（无新错误）和 UNI_OUTPUT_DIR 临时目录 H5 构建验证。

## 修复 AOE 技能（箭雨）卡顿
- 根因：【箭雨】命中 7 目标 + 4 障碍物 + 2 溅射时，AOE 范围特效已覆盖所有格子，但 processAOEAttackSkill 仍对每个目标/建筑调用 triggerSkillEffect（新增独立 skill-effect + 粒子），且 triggerHitFlash 会触发 triggerHitSpark（每目标 8 粒子）；叠加 CSS 中每个 `.effect-particle` / `.spark-particle` 都被加上 `will-change: transform, opacity`，一波战斗同时创建 300+ GPU 合成层，导致移动端合成器阻塞、零点几秒严重卡顿。
- 修复（src/pages/battle/battle.vue）：
  - 拆分 GPU 提示 CSS：特效层与技能/受击/死亡容器保留 `will-change`；大量重复的 `.effect-particle`、`.spark-particle`、`.summon-particle`、`.death-particle`、`.move-trail-particle`、`.trail-particle .trail-core/.trail-glow`、`.charge-effect .charge-spark` 改为 `will-change: auto`，避免单帧数百合成层爆炸。
- 修复（src/stores/gameStore.ts）：
  - processAOEAttackSkill 中 AOE 主目标、建筑、溅射目标统一 `triggerHitFlash(..., true)` 跳过 hitSpark 粒子；移除主目标和建筑处的冗余 `triggerSkillEffect`；障碍物清除不再触发 `triggerShake`。
  - triggerAOEEffects 改用 `splashBatch` / `batch` 一次性 `skillEffects.value = [...skillEffects.value, ...batch]` 批量追加，减少 Vue 响应式触发次数；AOE 粒子统一强制 reduced，且 generateParticles 新增 aoeRange 参数使 areaRange>=3 时只生成 1 粒子、areaRange>=2 时 2 粒子。
  - 特效分级阈值收紧：EFFECT_COUNT_WARN 90→60、LIMIT 150→100、EFFECT_MAX_QUEUE 220→160，让多目标技能更早进入降级。
- 验证：tsc 过滤检查本次修改零错误；UNI_OUTPUT_DIR 临时目录 H5 构建通过。下次实机测试箭雨时应不再出现零点几秒卡顿。
