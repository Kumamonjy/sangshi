## 一、项目概述

### 1.1 项目基本信息
- **项目名称**：苍穹战纪（末日家园：丧尸围城）
- **项目类型**：回合制战棋策略游戏
- **技术栈**：Vue 3 + TypeScript + Pinia + UniApp + Vite
- **目标平台**：H5网页端、微信小程序、App

### 1.2 核心玩法
玩家扮演人类阵营领袖，通过角色培养、装备强化、家园建设、战斗策略等玩法，体验六界纷争的史诗故事。

### 3.4 移动力计算逻辑
移动力计算涉及三个关键位置，均使用 `!== undefined` 替代 `||` 运算符，确保0值正确生效：

#### createBattleCharacter 函数（创建战斗角色）
```typescript
// 修改前：
const moveRange = template.moveRange || 2
const attackRange = template.attackRange || 1

// 修改后：
const moveRange = template.moveRange !== undefined ? template.moveRange : 2
const attackRange = template.attackRange !== undefined ? template.attackRange : 1
```

#### getCharacterMoveRange 函数（获取移动范围）
```typescript
// 修改前：
const baseMove = char.moveRange || 3

// 修改后：
const baseMove = char.moveRange !== undefined ? char.moveRange : 3
```

**注意**：JavaScript中 `0 || 3` 会返回 `3`，因为 `0` 是 falsy 值。当角色移动力为 `0` 时（如杀生樱），必须使用严格的 `undefined` 检查，否则会错误地回退到默认值。

## 四、技能系统详解

### 4.1 技能数据结构
```typescript
interface Skill {
  id: string                    // 技能ID
  name: string                  // 技能名称
  mpCost: number                // 法力消耗
  type: 'attack' | 'heal' | 'support' | 'summon' | 'special'  // 技能类型
  power: number                 // 威力百分比（如200表示200%攻击力）
  cooldown: number              // 冷却回合数
  range: number                 // 作用范围（0表示自身）
  targetCount?: number          // 目标数量
  areaRange?: number            // AOE范围
  description: string           // 技能描述
  attribute: Attribute          // 技能属性
  category: string              // 技能分类：指定/直线/横扫/AOE/heal等
  skillTypeTag: string          // 类型标签（攻击/治疗/辅助/特殊/召唤）
  rangeTag: string              // 范围标签（1格/2格/3格等）
  targetCountTag: string        // 目标数标签（1个/2个/AOE/直线等）
  statusEffect?: StatusType     // 附加状态效果
  statusEffectDuration?: number // 状态持续回合
  selfHealPct?: number          // 自身生命恢复百分比
  selfMpHealPct?: number        // 自身法力恢复百分比
  dispelRandomDebuffs?: number  // 驱散负面状态数量
  dispelAllDebuffs?: boolean    // 驱散所有负面状态
  shaQiCost?: number            // 煞气消耗
  reikiCost?: number            // 灵气消耗
  damageFormula?: string        // 伤害公式
  hpPct?: number                // 生命值百分比伤害
  lifesteal?: number            // 生命偷取比例
  selfStatusEffects?: StatusType[]  // 自身获得的状态效果
  selfHpCost?: number           // 自身生命消耗比例
  selfDefeat?: boolean          // 使用后自身战败退场
  summonZombie?: boolean        // 召唤丧尸
  clearObstacles?: boolean      // 清除障碍物
  createSnowTerrain?: boolean   // 创建雪地地形
  selfMaxHpBuff?: number        // 自身最大生命加成
  selfHpThreshold?: number      // 自身血量阈值（低于此值才能使用）
  stealBuff?: boolean           // 偷取目标正面状态
  effectType?: string           // 特效类型（fire/ice/thunder/wind/shadow等）
  rangeType?: 'diamond' | 'square'  // 范围类型（菱形/方形）
}
```

| 直线 | 直线范围 | 选择方向，对直线范围内敌人生效 | processLineAttackSkill |
| 横扫 | 矩形范围 | 选择方向，对矩形范围内敌人生效 | processLineAttackSkill |
| aoe | 范围AOE | 以自身为中心，对范围内所有敌人生效 | processAOEAttackSkill |
| heal | 治疗技能 | 恢复生命值/法力值 | processHealSkill |
| support | 辅助技能 | 增益类技能 | processHealSkill |

### 4.3 伤害公式（damageFormula）
| 公式代码 | 说明 | 伤害计算 |
|---------|------|----------|
| 默认 | 纯攻击力百分比 | `power/100 × attackPower - defense` |
| atk_plus_hp_pct | 攻击力+生命值百分比 | `power/100 × attackPower + hpPct × target.hp - defense` |
| move_based | 移动距离加成 | `(power + distance×20)/100 × attackPower - defense` |
| hp_lost_pct | 失血百分比加成 | `(power/100 + hpLostPercent) × attackPower - defense` |

## 五、特效系统详解

### 5.1 特效组件说明

#### 特效数据结构
```typescript
// 技能特效
interface SkillEffect {
  id: string
  row: number
  col: number
  color: string
  size: 'small' | 'medium' | 'large'
  timestamp: number
  attribute: Attribute
  skillType: 'attack' | 'heal' | 'support' | 'summon' | 'special'
  particles: Particle[]
  category?: 'aoe' | '轰炸' | '横扫' | '直线'
  fromRow?: number
  fromCol?: number
  direction?: 'up' | 'down' | 'left' | 'right'
}

// 投射物
interface Projectile {
  id: string
  fromRow: number
  fromCol: number
  toRow: number
  toCol: number
```

### 5.2 特效函数清单

| 函数名称 | 说明 | 参数 |
|---------|------|------|
| `triggerSkillEffect()` | 在指定位置触发单个技能特效 | row, col, attribute, size, skillType, category?, fromRow?, fromCol? |
| `triggerAOEEffects()` | 触发AOE范围特效（菱形/方形） | centerRow, centerCol, areaRange, attribute, rangeType, skillType, category? |
| `triggerAreaEffects()` | 触发指定位置列表的特效 | positions[], attribute, skillType, category?, direction?, fromRow?, fromCol? |
| `generateParticles()` | 生成粒子数组 | attribute, skillType → Particle[] |
| `triggerShake()` | 触发抖动效果 | row, col, type |
| `triggerHitFlash()` | 触发受击闪白效果 | row, col, attribute? |
| `triggerHitSpark()` | 触发受击粒子飞溅 | row, col, attribute |
| `showFloatingText()` | 显示浮动文字（伤害/治疗/法力） | row, col, value, type, attribute?, isShaking? |
| `triggerProjectile()` | 触发投射物动画 | fromRow, fromCol, toRow, toCol, type, attribute |
| `triggerDefeatAnimation()` | 触发击杀/退场动画 | row, col, defeatType ('kill' | 'self') |
| `triggerStatusApplyEffect()` | 触发状态施加视觉反馈 | row, col, statusType |
| `triggerSummonEffect()` | 触发召唤出场特效 | row, col, attribute |
| `triggerMoveTrail()` | 触发移动轨迹粒子 | fromRow, fromCol, toRow, toCol, isPlayer |

### 5.3 特效触发时机
1. **技能释放时**：`useSkill()` → 根据category调用对应处理函数 → 在处理函数中触发特效
2. **普通攻击时**：`executeNormalAttack()` → `calculateDamage()` → 触发特效
3. **移动时**：`moveCharacter()` → `triggerMoveTrail()`
4. **状态施加时**：`addStatusToCharacter()` → `triggerStatusApplyEffect()`
5. **击杀时**：`removeCharacterFromBattle()` → `triggerDefeatAnimation()`

### 6.1 技能使用主流程
```
useSkill(skillId, attackerId, targetId?)
  ├── 检查冷却、法力、灵气/煞气消耗

  │
  ├── [直线/横扫技能] (category === '直线' | '横扫')

  │       ├── 计算伤害
  │       └── 对目标造成伤害
  │
  ├── [指定技能] (category === '指定')

  │       ├── triggerHitFlash()  # 闪白
  │       ├── showFloatingText()  # 飘字
  │       ├── triggerSkillEffect()  # 技能特效
  │       ├── triggerProjectile()  # 投射物
  │       └── 触发状态效果
  │
  ├── [治疗技能]
  │   └── processHealSkill()
  │       ├── 计算治疗量
  │       ├── 治疗自身
  │       ├── 治疗范围内友方
  │       ├── 触发状态效果
  │       └── showFloatingText()  # 治疗飘字
  │
  └── [特殊技能]
      └── 按skillId特殊处理
```

### 6.2 AI决策主流程
```
executeAttackMode(char)
  ├── 获取可用技能列表
  │   ├── 检查冷却、法力、灵气/煞气消耗
  │   ├── 检查HP阈值要求
  │   └── 检查状态限制（沉默/恐惧）
  │
  ├── 评估所有技能效果
  │   ├── 攻击技能：计算最大伤害
  │   ├── 治疗技能：计算最大治疗价值
  │   │   └── 自身血量加成（<30%翻倍，<50%+50%）
  │   └── 选择最优位置移动
  │
  ├── 选择最佳技能和目标
  │   ├── 治疗技能治疗价值 > 攻击伤害 → 选择治疗
  │   └── 否则选择伤害最高的技能
  │
  └── 执行行动
      ├── 移动到最佳位置
      └── 使用最佳技能
```

## 十二、常见操作指南

### 12.1 新增角色
1. 准备角色头像图片，放入对应阵营目录
2. 在 `gameData.ts` 中添加角色配置（参考HIREABLE_CHARACTERS格式）
3. 添加升级成长属性（CHARACTER_GROWTH）
4. 配置技能列表（CHARACTER_SKILLS）
5. 添加头像路径映射

### 12.2 新增技能
1. 在 `SKILL_TEMPLATES` 中添加技能配置
2. 在需要使用该技能的角色的 `CHARACTER_SKILLS` 中添加技能ID
3. 如有特殊效果，在 `gameStore.ts` 中实现对应的处理逻辑
4. 如需特殊伤害公式，在对应处理函数中添加逻辑

### 12.3 添加新的伤害公式
1. 在 `gameStore.ts` 的 `processAOEAttackSkill()`、`processSingleOrMultiTargetSkill()` 中添加新的damageFormula处理
2. 或在 `useSkill()` 中为特定技能添加特殊处理

### 12.4 添加新的特效类型
1. 在 `Projectile['type']` 中添加新的投射物类型
2. 在 `getProjectileTypeForSkill()` 中添加映射逻辑
3. 在 `battle.vue` 中添加对应的渲染样式

### 12.5 测试与调试
- 运行 `npm run dev:h5` 启动开发服务器
- 打开浏览器查看效果
- 战斗日志会显示在界面底部，便于调试
- 使用 `GetDiagnostics` 检查TypeScript错误
