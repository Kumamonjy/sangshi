# 苍穹战纪 - 产品需求文档

## 1. 产品概述

### 1.1 产品名称
苍穹战纪

### 1.2 产品类型
回合制战棋策略游戏

### 1.3 核心玩法
玩家扮演人类阵营领袖，通过角色培养、装备强化、家园建设、战斗策略等玩法，体验六界纷争的史诗故事。

### 1.4 目标用户
喜欢战棋类、策略类游戏的玩家

### 4.3 技能效果机制（统一状态系统）
- **攻击力提升（状态）**：角色进入【愤怒/强力/凶悍/虚弱】等状态时，在基础攻击力上叠加百分比加成（或减益），持续到战斗结束
- **防御力降低（状态）**：目标进入【虚弱/愤怒/刚毅/不灭】等状态时，在基础防御力上叠加百分比加减
- **生命值上限提升（maxHp）**：红花绿叶技能可动态提升角色生命值上限，同时恢复等量生命
- **技能目标选择**：
  - 多目标技能（targetCount）：选择指定数量的目标
  - 位置指定技能（远程导弹）：选择任意格子为目标
  - HP限制技能（腐蚀粘液）：仅在生命值≤20%时可用
- **状态（Status）系统**：详见下方 4.4；新增状态只需在 `STATUS_CONFIG` 中注册，战斗结算函数自动生效
- **驱散（dispel）**：移除目标身上所有"负面"状态（如中毒、燃烧、流血、沉默、眩晕、紊乱、寒冷、瘸腿、虚弱、禁锢、迷离、心乱、脆弱、脆皮、削弱）。正/负面标签由状态配置中的 `tag` 字段决定（`positive` / `negative`）
- **回合恢复类状态**：愈合/再生（HP 恢复）；调息/静心（MP 恢复），回合结束时自动结算

## 7. 战斗系统

### 7.1 战斗基础规则
- **回合制**：玩家回合与敌人回合交替进行
- **移动规则**：每回合可移动1-5个网格（根据角色属性）
- **攻击规则**：移动后可攻击范围内敌人
- **技能系统**：技能消耗法力，有冷却时间
- **防御机制**：防御状态下防御力提高20%
- **被攻击抖动**：角色被攻击时触发抖动特效
- **瞄准准心**：天启炮锁定目标时显示准心特效

### 7.2 战斗模式

### 7.3 地形系统

|------|------|--------|--------|--------|
| 空地 | - | 是 | 否 | - |

### 7.6 伤害计算公式
```
最终伤害 = (最终攻击力 - 最终防御力) × 技能倍率
最小伤害：1

最终攻击力 = attacker.attack × (1 + Σ状态攻击加成% + attackBoost%)
  - 状态攻击加成：愤怒(+20%) / 强力(+10%) / 凶悍(+20%) 等
  - attackBoost：直接对攻击者附加的攻击百分比（当前仅【绝处逢生】的第一击使用）

最终防御力 = target.defense
              × (1 + Σ状态防御加成%：刚毅+30% / 不灭+50% / 愤怒-20% / 虚弱-50%)
              × 1.2 (如果目标处于防御姿态)
              × (1 - defenseReduction%)
              × (1 - defenseReductionPermanent%)
```

### 7.7 AI行动逻辑
- **目标优先级**：优先攻击角色和建筑，不攻击障碍物
- **伤害最大化**：选择能造成最多伤害的目标
- **移动后攻击**：先移动到合适位置再攻击
- **技能使用**：根据技能类型智能选择目标
  - 多目标技能（targetCount）：选择多个不同目标
  - 位置指定技能（如远程导弹）：选择敌人密集的位置
  - HP限制技能（如腐蚀粘液）：HP≤20%时优先使用

### 7.8 技能清除障碍物
- 攻击类范围技能可以清除范围内的障碍物
- 远程导弹：攻击范围内的障碍物同时被清除
- 恐怖尖叫：攻击范围内的障碍物同时被摧毁，并随机生成普通丧尸
- 红花绿叶技能特殊处理：对障碍物使用时，摧毁障碍物同时提高自身生命值上限（+攻击力的80%）并恢复同等生命值
- 对建筑目标使用时，对建筑造成伤害，同时根据技能特性触发自身buff

### 7.9 生命值上限（maxHp）与法力上限（maxMp）
- 战斗角色拥有独立的 `maxHp` 和 `maxMp` 字段，初始值为角色模板基础值 + 装备加成
- 技能（如红花绿叶）可动态提升 `maxHp`，提升后角色当前生命值同时增加同等数值
- UI 显示优先使用战斗角色自身的 `maxHp` / `maxMp`，确保属性变更被响应式跟踪

### 7.10 战斗记录系统
- **文字记录**：实时记录战斗中的所有行动
- **数据记录**：显示双方角色和建筑的总伤害/总治疗统计
- **统计范围**：包括已退场的角色和已摧毁的建筑
- **显示格式**：左侧角色图标，右侧柱状图和数字

## 9. 存档系统

### 9.1 存档内容
- 所有角色属性和装备
- 背包物品
- 家园建设状态（只保存有建筑的位置）
- 游戏时间和阶段
- 金币数量
- 角色等级和经验值

### 9.2 存档特性
- **HP/MP自动回满**：每次启动游戏，角色都会恢复到满HP满MP
- **技能冷却重置**：保存存档时，所有角色的技能冷却时间重置为0
- **战斗状态不保存**：只保存家园和角色成长内容
- **家园优化**：只保存有建筑的位置，空地不保存
- **技能简化**：技能不需要icon和description字段，仅保存技能id
- **avatar和isPlayerOwned字段不保存**：由角色模板动态获取

### 9.3 自动保存
- 家园修改自动保存
- 战斗结束自动保存
- 角色操作后自动保存

### 9.4 存档槽位
- 提供3个存档槽位
- 每个槽位可以自定义命名
- 存档显示保存时间和玩家信息

### 9.5 外部存储备份（Android）
- 支持自动备份到Android外部存储
- 存档文件位置：`Android/data/uni.app.UNISANSHI/apps/__UNI__6383D08/doc/SangshiGame/`
- 删除App后重新安装，启动时会自动尝试从外部存储恢复存档

### 9.6 剪贴板备份（推荐）
- **导出存档**：
  - 点击"📤 导出存档"按钮
  - 存档数据自动复制到剪贴板
  - 可粘贴到备忘录、云盘等位置保存
- **导入存档**：
  - 点击"📥 导入存档"按钮
  - 选择"剪贴板恢复"
  - 恢复成功后刷新存档列表
  - 支持取消操作
  - 显示错误信息前100个字符
